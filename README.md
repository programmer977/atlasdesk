# AtlasDesk

A ticket management system developed 
during a Fullstack TypeScript learning track.

## Technologies

- Node.js
- TypeScript
- npm
- Git

## Requirements

- Node.js 24
- npm

## Installation

1. Clone the repository.
2. Run `npm ci`.

## Development

Run:

`npm run dev`

## Type checking

`npm run typecheck`

## Build

`npm run build`

## Running the build

`npm start`
